## 🚀 Submission Guidelines

To keep your ownership legally clear and avoid code conflicts with other participants, please strictly follow this rule:

* **Dedicated Subfolders:** All code must be submitted inside your own personal subfolder within the `/projects/` directory (e.g., `/projects/your-name-webinar/`). 

*Do not modify any files outside of your designated folder.*
